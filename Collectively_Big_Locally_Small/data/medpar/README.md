# Arizona Medicare 1991 (`medpar`)

`medpar.csv` is the `medpar` data of the R package COUNT (Hilbe), as distributed by the Rdatasets collection
(https://github.com/vincentarelbundock/Rdatasets, `csv/COUNT/medpar.csv`), unchanged. 1,495 Medicare admissions in
Arizona in 1991 for one diagnosis-related group (DRG 112, percutaneous cardiovascular procedures), randomly sampled
from the national MedPAR file, with the provider (hospital) number. Variables: length of stay, HMO membership, white,
in-hospital death, age 80 or over, admission type (elective, urgent, emergency), provider.

Reference: Hilbe JM. Negative Binomial Regression, 2nd ed. Cambridge University Press; 2011. Hardin JW, Hilbe JM.
Generalized Linear Models and Extensions. Stata Press; 2001. Used by `simulations/real_networks.py`.
